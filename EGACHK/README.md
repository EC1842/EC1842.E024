# EGACHK — индексные регистры ЕГА на ЕС-1842

Программа для ДОС. Проверяет, меняют ли обращения к дискам и запись в
порты ввода-вывода индексы регистров видеоадаптера ЕС1842.Е024: индекс
секвенсора (порт 3C4h) и индекс графического контроллера (порт 3CEh).

Драйвер EGA.DRV Виндоус 3.0/3.1 ставит эти индексы один раз (3C4h = 2 —
маска плоскостей, 3CEh = 8 — маска битов), а дальше пишет только данные в
3C5h/3CFh. Если индекс 3C4h собьётся, маски плоскостей попадут в регистр
сброса (индекс 0) или синхронизации (индекс 1) секвенсора, и развёртка
срывается.

## Что делает

Ставит режим 10h и индексы 2 и 8, как у драйвера, выполняет действие и по
видеопамяти проверяет, остались ли индексы на месте. Действия:

- INT 13h: сброс НГМД, чтение сектора с A:, чтение сектора с 80h;
- запись в порты 3F2h, 3F7h, 1F2h–1F6h, 3F6h, 172h–176h, 376h, 3D4h;
- две нарочные записи в 3C4h и 3CEh — контроль, они обязаны дать сбой;
- по 20 чтений с A: и 80h;
- перебор портов вида xx4h (42 порта от 004h до 3F4h): запись в порт —
  сбивается ли индекс 3C4h, запись в порт+1 — попадает ли она в данные 3C5h.

Итог по каждому действию: `OK` — индексы целы, `SEQ sbit` — сбит индекс
3C4h, `GC sbit` — сбит индекс 3CEh. В конце — список портов, которые
задевают ЕГА.

## Запуск

`EGACHK` из ДОС, без Виндоус, с дискетой в A:. Не запускать под монитором
286 режима: перебор пишет в порт 0C4h контроллера виртуальной памяти.

## Результат на ЕС-1842 с ЕС1842.Е024

Индекс 3C4h сбивает запись в **любой** порт с младшей тетрадой адреса 4h —
во всех проверенных портах от 004h до 3F4h. Данные 3C5h не задевает ни один
порт.
Защёлка индекса секвенсора на плате стробируется только разрядами A3–A0 и
сигналом -IOW, без выбора платы.

В обычной работе такие порты пишут:

- БСУВВ НГМД — 004h (адрес канала 2 ПДП);
- НМД IDE — 1F4h / 174h (младший байт цилиндра);
- INT 10h — 3D4h (курсор);
- обработчик клавиатуры — 064h;
- КВП — 0C4h (INT 15h AH=87h, драйверы расширенной памяти).

Поэтому программа, которая пишет секвенсор ЕГА этой платы, должна каждый раз
писать индекс и данные вместе (`OUT DX,AX` с DX = 3C4h).
